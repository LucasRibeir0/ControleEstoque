# Controle de Estoque em Java

Este é um projeto que estou desenvolvendo enquanto estudo Java e programação orientada a objetos.

A ideia surgiu como uma forma de colocar em prática os conceitos que venho aprendendo, construindo um sistema de controle de estoque aos poucos, conforme avanço nos estudos.

Nesta primeira versão, o programa funciona pelo console e permite cadastrar produtos, listar os itens, atualizar quantidades, remover produtos e consultar o total de unidades em estoque.

### O que pratiquei até aqui

Durante o desenvolvimento, trabalhei principalmente com:

- Classes, objetos e construtores;
- Encapsulamento e métodos;
- `ArrayList` para armazenar os produtos;
- Estruturas de repetição e condicionais;
- Retornos de métodos com `boolean`, `int` e `void`;
- Expressões lambda, utilizando `removeIf()`.

Uma parte importante desse processo foi entender melhor como organizar as responsabilidades entre as classes `Produto` e `Estoque`, em vez de concentrar toda a lógica na classe principal.

### Como está o projeto atualmente?

Por enquanto, os produtos ficam armazenados em memória, ou seja, os dados não são mantidos quando o programa é encerrado.

A próxima etapa será estudar Spring Boot e integrar o projeto a um banco de dados MySQL. Depois, pretendo desenvolver uma API REST e, futuramente, uma interface para interagir com o sistema.
